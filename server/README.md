# server

The Cloudflare Worker backend for online play: accounts, cloud saves, friends, reports and bans, server-graded progress, and the Durable Objects that host room sockets. Pure rules live in `src/` and are Node-tested; runtime adapters in `src/worker/` wire them to Cloudflare. The client reaches it through `src/net/client/` (see `docs/security.md` for the threat model).

## Files

| File             | What it does                                                                                                                                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `wrangler.jsonc` | Worker config: entry `src/worker/index.ts`, Durable Object bindings (`ROOMS`, `DIRECTORY`, `RATE_LIMITER`), the D1 binding `DB` (placeholder id), `ALLOWED_ORIGINS`, and the Vite `dist/` as static assets (only `/api/*` and `/ws/*` run Worker code) |
| `tsconfig.json`  | Strict TypeScript config for `src/worker` plus the generated `worker-configuration.d.ts` (run by `npm run typecheck:server`)                                                                                                                           |

## Subfolders

- [`migrations/`](migrations/README.md): D1 schema migrations.
- [`scripts/`](scripts/README.md): the local end-to-end smoke test.
- [`src/`](src/README.md): pure server modules and their tests.
- [`src/worker/`](src/worker/README.md): the Worker entry and Durable Object adapters.

## Notes

- `worker-configuration.d.ts` is generated by `npm run types:server` (also run by `npm run lint` and `npm run typecheck`); it is not hand-edited.
- Local run: `npm run dev:server`, after applying migrations with `npx wrangler d1 migrations apply DB --local --config server/wrangler.jsonc`.
- Never deploy, run `wrangler deploy` or log in to Cloudflare without the owner's approval.
