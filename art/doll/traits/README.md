# art/doll/traits/

Transparent 2D trait images for the layered 2D doll, one PNG per option, registered to `../template-doll-golden.png`. `../compositor.html` stacks them; no code under `src/` loads them. Part of the [doll folder](../README.md).

`transparent/` also holds three loose files beside the folders: `eyeliner-winged-doll-lashes.png`, `hair-blonde-fulani-braids.png` and `jewelry-gold-bamboo-hoops.png`.
