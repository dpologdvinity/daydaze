## How to work (what made the last session fast)

- **You manage, agents build.** Spawn Sonnet agents (owner's rule: Sonnet only),
  each in `.worktrees/<name>` on `feat/<name>` with `node_modules` symlinked;
  brief them with `docs/agents/agent-rules.md`. Review their screenshots
  yourself before merging; send work back when it isn't at the quality bar.
- **Heavy work runs on GitHub Actions, not the owner's machine** (the owner
  uses it and it's CPU-only SwiftShader):
  - push `feat/**`, `fix/**`, `perf/**` or `ci/**` → `verify.yml` (~1.5 min);
  - `gh workflow run browser-test.yml --ref <branch> -f grep="<test title>"`;
  - `gh workflow run screenshots.yml --ref <branch> -f shots="<names>"`, then
    `gh run download <id> -n screenshots -D /tmp/shots-<id>`;
  - `profile.yml` for frame-time/load profiling (see `scripts/perf-profile.ts`).
- **Merge** with `bash docs/agents/scripts/land.sh <branch> <worktree> "<message>"`:
  it rebases onto `main`, pushes `ci/land-<w>-<sha>`, waits for GitHub's
  verify, then merges `--no-ff` and pushes. It does not roll back a failed
  rebase or verify: fix in place and rerun. For additive conflicts (lists,
  imports, table rows) `docs/agents/scripts/keepboth.sh` and `union_assets.py`
  help, but check the result: keep-both has dropped closing braces and
  duplicated imports before.
- **Assets:** the owner's packs are release files in the private repo
  `dpologdvinity/daydaze-assets` (releases `packs`, `hair`, `animals`):
  `gh release download packs -R dpologdvinity/daydaze-assets -p '<file>'`. The
  Mixamo FBX library is the private repo `dpologdvinity/mixamo` (also cloned at
  `~/git/mixamo`, symlinked as the git-ignored `mixamo/`). Licenses and where
  each pack belongs: `docs/asset-inventory.md`. Never ship NC/ND assets or real
  brands.

## Gotchas learned the hard way

- `Agent` with `isolation: "remote"` silently runs **locally** (in
  `.claude/worktrees/agent-*`); it does not offload CPU. Renice your own
  session (`renice -n 19 -p <claude pid>`) so every agent command inherits low
  priority, and keep Blender/gltf-transform runs under `nice -n 19`, one Blender
  at a time.
- **Never kill a process you didn't start**: an agent killed one of the
  owner's own jobs. Record `$!` at launch; never `pkill -f`.
- Agents' force-pushes are denied: after a rebase, push to a fresh
  `ci/<name>-<sha>` ref instead.
- A workflow can only be dispatched on a branch that contains the workflow
  file; rebase old branches first.
- Screenshot runners use UTC daytime and lack the display font unless the shot
  pins `?time=`; judge content, not the font.
- `/tmp` can be wiped (cleanup or a WSL crash): helpers live in
  `docs/agents/scripts/`, the brief in `docs/agents/agent-rules.md`.
- Claude agents share one usage limit and tend to run out together; save
  partial work as WIP commits and resume later.
- Codex was out of quota until 2026-11-10; Antigravity's Claude models were
  out until about 2026-11-13 (its Gemini still worked). Check before using.
