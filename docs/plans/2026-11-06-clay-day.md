# Clay Day Implementation Plan

**Goal:** Build the requested pottery studio on Gallery Row, including a playable wheel, glazing, kiln, prizes and a saved apartment piece.
**Architecture:** Reuse room/door registration, scene props, the shared reactive store and prize desk. Pure profiles and validation live in `src/game/pottery.ts`; the room and panel share a session. Update lathe geometry only on input, spin by rotation only.
**Tech Stack:** Existing TypeScript, React, R3F, Three.js and Node tests; no dependencies.
**Spec:** User's Clay Day task and `/tmp/daydaze-agent-rules.md`.

## Constraints and decisions

Use downloaded CC0/CC-BY props and synchronized credits; never read .env, deploy, push or merge. Keep strict types and no frame allocations. Save the latest fired piece (replacing the previous display). Bowl, vase and mug targets use eight profile bands, separate left/right radii and fixed clay volume to determine thickness. A collapsed pot cannot fire or earn a prize. Keyboard sliders offer every pointer action. Kiln firing is a short cancellable timer. Use supplied ports and the global browser lock.
