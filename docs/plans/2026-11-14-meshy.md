## How

- Use the image route for accuracy (these are cultural objects that must look
  right): `meshy_text_to_image` (nano-banana, 3 credits), check the image, then
  `meshy_image_to_3d` with `input_task_id` (textured in one task). Check the
  image-to-3D cost in the tool's description first; budget about 35 credits
  per finished model, so about 70 models fit.
- Smart topology for game use (`meshy-t2.5`, `target_polycount` 3,000 for
  props, 8,000 for the few hero pieces).
- Prompt style line: "stylized semi-realistic game prop, bright saturated
  colors, clean shapes, no text, no logos". No real brands. Made-up names only
  (on jeepneys, stalls and floats, paint them on afterwards if needed).
- Downloads to `art/meshy/raw/` (git-ignored), prompt and task id per model in
  `art/meshy/prompts.json`. Integration after midnight: gltf-transform
  optimize (meshopt, webp), `public/models/meshy/<group>/`, recorded in
  `docs/assets.md` and `src/game/credits.ts` as generated with Meshy.
