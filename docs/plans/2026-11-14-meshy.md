## Rules

- Download, don't build still holds: Meshy is only for things with no good
  free model (checked in `docs/asset-inventory.md`, Kenney, Poly Pizza,
  Quaternius). It replaces the boxes and stand-ins that are left.
- Game assets use smart topology: `meshy_text_to_3d` with `meshy-t2` and a
  `target_polycount` (5 credits), then `meshy_text_to_3d_refine` for texture
  (10 credits): **15 credits per prop**. A hero prop seen up close may use
  `meshy-6` (20 + 10 = 30).
- Style line in every prompt: "stylized low-poly game prop, clean shapes,
  bright saturated colors, no text, no logos, no brand names". No real brands
  (alcohol, tobacco or otherwise).
- Every result goes through
  `npx -y @gltf-transform/cli@4.5.1 optimize in.glb out.glb --compress meshopt --texture-compress webp`,
  lands in `public/models/meshy/<group>/`, and is recorded in `docs/assets.md`
  and `src/game/credits.ts` as "generated with Meshy (owned)".
- Raw downloads go to `art/meshy/raw/` (git-ignored); the prompt and task id of
  each are kept in `art/meshy/prompts.json` so a model can be traced.

   looks wrong (5 credits lost, not 15).
3. Download every finished model to `art/meshy/raw/` as it completes; keep
   `prompts.json` current.
4. After midnight (no credits needed): optimize, check sizes against the
