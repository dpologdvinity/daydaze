# src/game/dance

How dolls move: dance data, clip choice, walking pace and posture transitions. The doll rig in `src/client/avatar/` plays what these modules pick; nothing here touches React or three.js.

## Files

| File                                                               | What it does                                                                                                                                                                                                      |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `moves.ts` (+ `moves.test.ts`)                                     | Every dance move as data (looped joint-angle clips on the doll rig) plus the style groups.                                                                                                                        |
| `groups.ts` (+ `groups.test.ts`)                                   | The Dance picker's styles: every move sits in exactly one group, which a test checks.                                                                                                                             |
| `clips.ts` (+ `clips.test.ts`)                                     | Which baked clip a doll plays, frame by frame, from the Mixamo clips baked onto its skeleton.                                                                                                                     |
| `mocap.ts`, `mocapSources.ts`, `mocapTypes.ts` (+ `packs.test.ts`) | Clip tables generated by `art/doll/blender/mocap.py`: the clips, their sources and the pack names. Do not edit by hand. The test checks every pack is well formed and the core pack stays within its size budget. |
| `idlePlan.ts` (+ `idlePlan.test.ts`)                               | What a standing doll does while she waits: breathing, weight shifts and fidgets, with a temperament picked per NPC.                                                                                               |
| `conversation.ts` (+ `conversation.test.ts`)                       | How a standing group talks: who has the floor, what her hands do and how the others listen.                                                                                                                       |
| `locomotion.ts` (+ `locomotion.test.ts`)                           | The small clips around walking: setting off, arriving and turning.                                                                                                                                                |
| `pace.ts` (+ `pace.test.ts`)                                       | How fast the player moves on foot: a stroll for a short trip, a hurry for a long one.                                                                                                                             |
| `stride.ts` (+ `stride.test.ts`)                                   | How fast a walk clip plays so the legs keep pace with the ground.                                                                                                                                                 |
| `transitions.ts` (+ `transitions.test.ts`)                         | One-shot clips that join two postures, such as sitting down onto a seat and standing up.                                                                                                                          |
| `seatActions.ts` (+ `seatActions.test.ts`)                         | What a seated doll does with her hands: an emote, a table or desk idle, or her chosen pose.                                                                                                                       |
| `couple.ts` (+ `couple.test.ts`)                                   | Partner dancing: where two dolls stand and the follow's pose as a mirror of the lead's.                                                                                                                           |
| `together.ts` (+ `together.test.ts`)                               | Emotes for two players, invited over the `game` relay, with mirrored roles.                                                                                                                                       |
| `reach.ts` (+ `reach.test.ts`)                                     | Height adjustment for a kiss between dolls of different heights.                                                                                                                                                  |
| `sync.ts` (+ `sync.test.ts`)                                       | Dancers near each other take their place in the loop from a shared clock, so they move as one.                                                                                                                    |
| `venueDances.ts` (+ `venueDances.test.ts`)                         | What each venue's dancers dance, how a club night swaps the style and when the floor is called to one.                                                                                                            |
